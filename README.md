# Reading Notes

面向 AI 朗读的核心读书内容仓库。每篇笔记用约三十分钟的自然中文，详细讲清一本书的核心问题、结论、论证、概念和适用边界，适合在空闲时间戴耳机收听。

## 使用方式

在 Kiro 中直接发送一个或多个书名，例如：

```text
原则
```

或：

```text
原则、穷查理宝典
```

仅发送书名或明确要求生成读书笔记，即表示授权 Kiro 自动完成：

1. 识别书籍并检查是否已存在；
2. 分配编号并生成 AI 朗读版笔记；
3. 更新本页索引；
4. 校验内容、听感和 Git 变更；
5. 创建 commit 并推送到 `origin/main`；
6. 返回文件路径、commit hash 和推送状态。

以下情况会先询问：

- 书名、作者或版本存在歧义；
- 仓库中已有同一本书；
- 目标文件或索引存在未提交修改；
- Git 分支、远端状态或认证不满足安全推送条件。

完整规则见 [《读书笔记生成约定》](读书笔记生成约定.md)，格式见 [AI 朗读版模板](NOTE_TEMPLATE.md)。

## 朗读稿结构

新版笔记只保留书籍信息、核心问题与结论、论证主线、核心概念、关键洞见、局限与边界。资料核验在内部完成，不展示制作说明、证据标签、行动清单、问答、参考资料、延伸书单或生成时间。

## 目录结构

```text
reading-notes/
├── README.md                 # 项目说明与唯一书目索引
├── NOTE_TEMPLATE.md          # AI 朗读版标准模板
├── 读书笔记生成约定.md        # 自动生成、校验与 Git 流程
└── notes/                    # 按编号保存读书笔记
```
