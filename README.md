# Reading Notes

个人结构化读书笔记仓库。每篇笔记提炼一本书的核心论点、知识框架、关键案例、行动建议与批判性思考。

## 使用方式

在 Kiro 中直接发送一个或多个书名，例如：

```text
原则
```

或：

```text
原则、穷查理宝典
```

仅发送书名或明确要求“生成读书笔记”，即表示授权 Kiro 按项目约定自动完成以下流程：

1. 识别书籍并检查是否已存在；
2. 按顺序分配编号，每本书生成一份 Markdown 笔记；
3. 更新本页的笔记索引；
4. 校验文件格式、内容结构和 Git 变更范围；
5. 创建 Git commit 并推送到 `origin/main`；
6. 返回文件路径、校验结果、commit hash 和推送状态。

以下情况会先询问，不会擅自生成或覆盖：

- 存在同名书、作者或版本歧义；
- 仓库中已有同一本书；
- 目标文件或索引存在未提交修改；
- 当前分支、远端状态或认证不满足安全推送条件。

完整执行规则见 [《读书笔记生成约定》](读书笔记生成约定.md)，标准格式见 [笔记模板](NOTE_TEMPLATE.md)。

## 笔记结构

新版笔记以掌握核心内容为目标，统一回答书籍的核心问题、作者结论、论证链、核心概念、关键洞见、适用边界和主动回忆问题。报告会明确区分“原书精读”与“公开资料研读”，并标注观点、案例和推论的依据。

## 目录结构

```text
reading-notes/
├── README.md                 # 项目说明与唯一书目索引
├── NOTE_TEMPLATE.md          # 新笔记标准模板
├── 读书笔记生成约定.md        # 自动生成、校验与 Git 流程
└── notes/                    # 按编号保存读书笔记
```
