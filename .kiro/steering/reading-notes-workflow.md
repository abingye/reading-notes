# 读书笔记自动化工作流

本仓库用于维护结构化读书笔记。

当用户的消息仅包含一个或多个书名，或明确要求生成某本书的读书笔记时：

1. 必须先读取并严格执行 #[[file:读书笔记生成约定.md]]。
2. 使用 #[[file:NOTE_TEMPLATE.md]] 作为新笔记的唯一格式模板。
3. 更新 #[[file:README.md]] 中标记区内的书目索引。
4. 将这类输入视为用户已明确授权本次生成文件、创建 Git commit，并推送到 `origin/main`。
5. 除歧义、重复书、目标文件已有修改、Git 分支或远端异常、认证失败外，完整执行到推送验证，不中途要求重复确认。

如果用户是在询问某本书、讨论书中观点或要求修改现有笔记，而不是仅发送书名或明确要求生成，则按普通请求处理，不自动触发新增笔记和 Git 推送。
